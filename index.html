    cubagem-stone projects/cubagem-stone

    Problema: A cubagem correta de um produto é o que define o custo de frete. Contudo, marketplaces como Mercado Livre e Amazon não exigem as dimensões do item aos vendedores; quando exigem, frequentemente as proporções são imprecisas. Sem esse dado confiável, não há como otimizar a embalagem nem prever o custo logístico.

    Solução: Aplicação web com agente LLM que infere as dimensões de um produto a partir da descrição em texto ou imagem. Conforme o uso, toda estimativa confirmada alimenta um banco de dados SQLite que é consultado antes de qualquer nova estimativa. O sistema fica progressivamente mais barato e determinístico conforme o catálogo cresce, sem depender do LLM para itens já conhecidos.

    Por quê: alucinação numérica é inaceitável quando o número vira custo de frete. Tirando o estado do modelo e colocando no banco, o erro para de ser invisível.
